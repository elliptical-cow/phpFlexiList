📋 {{ appName }} User Guide

🚀 Getting Started

Create New List

  1. Click "✅ Create New List" on the homepage
  2. The server generates a random list ID and a separate access token
  3. You are redirected directly to the new list
  4. Bookmark the URL - this is your permanent list link
  5. Share the URL with others for collaboration
URL Format:
/app?id=<list-id>#token=<access-token>
⚠️ Important: The access token is generated securely by the server.
Anyone who knows the complete link can edit the list.
💡 Tip: No signup is required. Keep the complete list URL private.

✏️ Basic Functions

➕ Add Entries

Click "+ New Entry" at the end of the list or in categories.

✏️ Edit Text

Click on titles or entries to edit. Enter = Save, Esc = Cancel.

✅ Check Off

Click checkbox = Mark as done. Via ⋯-menu completed entries can be hidden.

📝 Change List Title

Click on the list title at the top to give your list a custom name. (A good title also helps the AI with categorization.)

🗂️ Create Categories

Via ⋯-menu → "➕ New Category". Unlimited nesting possible.

📁 Organization with Categories

Creating Categories

  1. Click "➕ New Category"
  2. Name your category (e.g. "Groceries", "Work Tasks")
  3. Add items into the category
  4. Create unlimited nested sub-categories

Category Functions

• Expand/Collapse: Click the triangle (▼/▶) to show/hide category contents
• Drag & Drop: Drag items between categories to reorganize
• Nested Structure: Create categories inside categories for complex organization

🤖 AI Auto-Categorization

Automatic Organization

⋯-menu → "🤖 Auto-categorize" lets AI automatically organize your entries into meaningful categories.

How it works:
  1. Enter at least 5 entries in the list
  2. ⋯-menu → "🤖 Auto-categorize" click
  3. AI creates appropriate categories and assigns entries
⚠️ Privacy: When enabled, list contents are sent to the AI provider selected by the operator. Review that provider's terms before using this feature. Consent is stored locally for 28 days.
